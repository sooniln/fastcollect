# Module FastCollect

A multi-platform library for high-performance primitive collections in the JVM/Kotlin ecosystem. FastCollect is highly
memory efficient and performant, and is competitive with - if not faster than - every primitive collections library in
the JVM ecosystem. As a drop-in replacement for standard JRE collections, FastCollect generally reduces memory usage
by 4–5× and improves CPU performance by 2-3×.

See the [README](https://github.com/sooniln/fastcollect) for quick start, usage and benchmarks.
